# Contributing

## Corrections and missing records

If something in the record is wrong, or a parcel/park/building isn't
tracked yet, please [open an issue](../../issues/new/choose) using the
"Correction" or "Missing record" template. That's the intake for changes
to the data.

**Pull requests against the data directories are not accepted as
corrections.** Everything under `data/`, `api/v1/`, and
`docs/record-schema.md` is generated by a private build pipeline and
replaced wholesale on every publish — as is `site/`, the rendered
website, which is generated and replaced the same way and so is not a
pull-request surface either — a pull request touching those paths
would simply be overwritten on the next publish, so it can't be the
mechanism for fixing the record. File an issue instead, and once a
correction is verified and applied, it will show up in
`data/changelog.csv`.

## Everything else in this repository

Pull requests are welcome for the repository's own furniture: the attest
workflow (`.github/workflows/attest.yml`), issue templates, documentation
(`README.md`, `docs/verify.md`, this file), and licensing. Open a pull
request as usual and explain what you're changing and why.
