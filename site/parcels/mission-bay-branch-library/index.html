Research notes

Mission Bay Branch Library, 960 4th St -- San Francisco Public Library branch, 7,499 sq ft, single story, built 2005 (DataSF Assessor Historical Secured Property Tax Roll: property_class_code_definition 'LIBRARY', year_property_built 2005). Blklot 8708110 confirmed against data/raw/parcels.geojson (from_address_num 960, street 04TH ST); the Assessor tax roll's own property_location field for this blklot reads '201 BERRY ST', a stale corner-frontage address rather than the library's current 4th St mailing address, the same kind of discrepancy already documented for The Exchange on 16th.
