Commercial · Potrero Power Station

Open questions

Looked for, not found

  • No construction-start date is stated in any source found; the most recent primary source found (the 2024 annual compliance report, submitted March 2025) describes only design approval and does not report construction underway on Station A.
  • The D4D's Figure 6.2.3 shows a 230-ft upper-height callout for part of Block 15, while the 2022 design review approval describes a 205-ft total height and references '145-foot and 160-foot' prevailing maximums for the vertical addition; these figures are not reconciled here.
  • The Chronicle's July 2026 report of a proposed +30 ft height increase for Station A is tied to a Development Agreement amendment (BOS File 260724 / Planning Code ordinance File 260770) that was still pending Board of Supervisors action as of this dossier's last-verified date; it is recorded here as an expected/proposed change, not an adopted one.
  • No source found stating a cost estimate for Station A's rehabilitation and vertical addition.
  • The hosted image (potrero_block15_station_a_deir_2018.jpg) is kind: before, but it is not a single photograph -- it is a composite DEIR report page carrying six separate existing-conditions photos of Station A's turbine hall and machine shop, each with its own caption. Flagging in case a document-style kind fits it better than a single before photo.
  • The newly added now photo is dated 2020-02-17; labeled now rather than before because the most recent primary source found (the 2024 annual compliance report, submitted March 2025) still describes no construction activity on Station A beyond design approval, so the building's exterior likely hasn't changed since. If construction has started since this dossier's last_verified date, this photo is out of date and should be revisited.

About this shape

Accuracy

APPROXIMATE -- this block is not yet built and does not correspond to any subdivided Assessor parcel: it currently sits on vacant/graded land within the former power station site (unaddressed in DataSF's Assessor roll). Traced from an adopted regulatory diagram via multi-point real-street georeferencing (see digitization_method), but this diagram is dated 2020 and may not reflect later design changes (as already found for the UCSF/Sophie Maxwell area -- see digitization_method). Treat vertex positions as accurate to roughly 10-25m, not survey-grade, and treat the block's applicability itself as somewhat more provisional than Mission Rock's or Pier 70's equivalent entries. Rebuilt 2026-09-16 via GDAL GCP/TPS georeferencing -- see digitization_method. Re-measured 2026-09-16 (third pass) in a single consistent pixel-detection pass across the whole block layout -- see digitization_method. Re-corrected 2026-09-16 (fourth pass) after fixing a mis-measured GCP -- see digitization_method.

Traced from

Potrero Power Station Design for Development, Figure 6.2.3 - Building Height Plan (p.245).

Why there’s no DataSF parcel

A real Assessor parcel may exist under this block (part of the site's larger, largely unaddressed footprint), but it has not been subdivided per the masterplan's individual named blocks -- this uses hand-traced approximate geometry instead.

Planning context

Station A: the site's historic 1901 unreinforced-brick turbine hall, standing vacant/unused. Adaptive reuse into ~403,750 GSF office/R&D (plus 16,225 sf of terraces and a public 'Turbine Hall'/mid-block passage to Power Station Park) via 8 new floors built above the retained historic shell, designed by Herzog & de Meuron with Adamson Associates, approved by the SF Planning Commission Oct 22, 2020 -- all confirmed directly against the actual Planning Commission approval packet. Max height 205 ft (historic base + addition). Construction had NOT started as of an August 2025 source -- the site's flagship preservation project, reversing an original demolition plan after Historic Preservation Commission/SF Heritage advocacy.
