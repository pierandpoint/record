    Blocks 18B/18C corrected. A secondhand report that UCSF's own June 2025 CAC presentation (campus map updated December 2024) renumbers this row of blocks was independently checked. On review it was identified as the existing UCSF at Mission Bay Child Development Center (727 Nelson Rising Lane, operating since 2006), so 18B was renamed 18C, with the shape unchanged and the status changed to existing/interim ahead of a long-term open-space redesignation. With 18C's identity established, the 18A parking lot was extended east (~1,197 sqm) to close the access-lane gap that used to separate it from 18C, then re-split into new 18A and 18B of equal area, so the row now runs 18A/18B (parking) back-to-back with 18C (the existing childcare building). The childcare-center identification is an on-the-ground read, not independently confirmed by any source checked at the time, and is flagged as such in the record. A September 2026 accuracy check found that the UCSF deck cited (Dec 2024 map) lists Block 18C among 'undeveloped parcels remaining' with 'Open Space (Near term: Childcare Center)', which does not by itself show an existing building; no source read gives the 727 Nelson Rising Lane address or a 2006 start. The existing/interim status therefore rests on that on-the-ground read alone and needs a source.
